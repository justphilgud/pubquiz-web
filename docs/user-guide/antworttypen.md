# Antworttypen

Unterstützt werden Auswahlfragen, offene Fragen und Fragen mit mehreren Antwortfeldern. Für jede Antwort sollen Zusatzinformationen für die Auflösung gepflegt werden können.

Das Fragentemplate **What the Meme!** lässt Teams ein vorgegebenes Bild mit einem oberen und unteren Memetext beschriften. Im Editor und in der Fragensuche wird es unter diesem Namen geführt.

Geplante Vorlagen: FaceMorph, Musik rückwärts und Mehrfeld-Fragen mit editierbaren Labels.
