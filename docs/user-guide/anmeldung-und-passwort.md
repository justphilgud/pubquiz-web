# Anmeldung und Passwort

## Anmeldung

1. Login-Seite öffnen.
2. E-Mail-Adresse und Passwort eingeben.
3. Anmeldung bestätigen.

## Erzwungener Passwortwechsel

Beim ersten Login oder nach einem administrativen Zurücksetzen muss ein neues Passwort vergeben werden.

## Passwortverwaltung

Angemeldete Benutzer können ihr Passwort im Profil ändern. Administratoren können Passwörter in der Benutzerverwaltung zurücksetzen.

Ein selbstständiger Passwort-Reset per E-Mail ist derzeit nicht vorgesehen.
