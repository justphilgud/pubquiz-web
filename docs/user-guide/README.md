# Benutzerhandbuch

Dieses Handbuch beschreibt den auf Preview geprüften Produktstand. Je nach Rolle sind nur die freigegebenen Bereiche sichtbar.

## Rollen und Einstiege

- **Administrator:** Benutzer, Kategorien, globale Teamverwaltung und Freigaben.
- **Editor:** Fragen, Story-Elemente und Umfragen erstellen und bearbeiten.
- **Eventmanager/Moderator:** eigene Eventreihen, Quizze, Moderation und Teams im zugewiesenen Scope.
- **Quizteam:** einem Quiz beitreten, das globale Teamprofil pflegen und Antworten abgeben.
