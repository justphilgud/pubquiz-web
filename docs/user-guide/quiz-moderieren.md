# Quiz moderieren

Die Moderationsansicht zeigt aktuelle Präsentation, nächste Folie, Moderationsnotizen, Zusatzinformationen, Teamstatus, Timer und Zeitprognose.

Der Moderator navigiert, steuert Medien und wechselt in Zwischen- und Endauswertung. Hotkeys sind teilweise umgesetzt; eine Fernbedienung ist für später geplant.
