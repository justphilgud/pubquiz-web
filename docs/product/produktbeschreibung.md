# Produktbeschreibung

Phil Gud Entertainment entwickelt Software und Konzepte für interaktive Live-Veranstaltungen.

Das erste aktive Produkt ist **ungegoogelt**, eine Plattform für Live-PubQuiz-Veranstaltungen. Sie unterstützt Fragenverwaltung, Quizplanung, digitale Teamteilnahme, Moderation, Präsentation und Auswertung.

Langfristig sollen digitale, hybride und vollständig offline durchführbare Veranstaltungsformate unterstützt werden.
