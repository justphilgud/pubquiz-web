# Phil Gud Entertainment

Phil Gud Entertainment entwickelt Software und Konzepte für interaktive Live-Veranstaltungen. Ziel ist es, Moderatoren und Veranstaltern Werkzeuge bereitzustellen, mit denen Veranstaltungen professionell vorbereitet, durchgeführt und ausgewertet werden können – digital, hybrid oder vollständig offline.

Das erste aktive Produkt ist **ungegoogelt**, eine Plattform für Live-PubQuiz-Veranstaltungen. Sie unterstützt die Erstellung und Verwaltung von Fragen, die Zusammenstellung von Quizzen, die digitale Teilnahme von Teams, die Moderation, Präsentation und Auswertung.

Weitere Produktideen sind PowerPoint Karaoke, Bingo und Bullshit Bingo. Diese Formate sollen perspektivisch auf einer gemeinsamen technischen Grundlage aufbauen.
