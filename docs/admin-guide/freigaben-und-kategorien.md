# Freigaben und Kategorien

## Fragenfreigabe

Von Editoren erstellte Fragen werden nicht automatisch freigegeben. Administratoren prüfen und veröffentlichen diese Fragen.

## Kategorien

Administratoren verwalten die verfügbaren Kategorien.

Für Version 2.0 ist vorgesehen, dass Editoren keine neuen Kategorien anlegen können. Stattdessen sollen sie über ein Bemerkungsfeld Hinweise an den freigebenden Administrator hinterlassen können.
