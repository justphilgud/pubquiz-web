# Benutzer verwalten

## Benutzer anlegen

Administratoren können neue Benutzer anlegen und ihnen eine Rolle zuweisen.

## Rollen

Derzeit sind mindestens folgende Rollen vorgesehen:

- Administrator
- Editor

## Passwort zurücksetzen

Administratoren können das Passwort eines Benutzers zurücksetzen. Beim nächsten Login kann ein Passwortwechsel erzwungen werden.

Ein selbstständiger Passwort-Reset per E-Mail ist derzeit nicht vorgesehen.
