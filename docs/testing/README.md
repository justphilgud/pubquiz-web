# Qualitätssicherung

## Grundsatz

Akzeptanzkriterien sollen so formuliert sein, dass daraus direkt Testfälle abgeleitet werden können.

## Testarten

- Abnahmetest
- einmaliger Test
- kleine Regression
- große Regression
- automatisierter Test

## Vorgehen bei Änderungen

Bei jedem Feature wird geprüft:

1. Ist ein neuer Testfall erforderlich?
2. Muss ein bestehender Testfall angepasst werden?
3. Gehört der Test zur kleinen oder großen Regression?
4. Ist eine Automatisierung sinnvoll?
5. Welche Dokumentation muss aktualisiert werden?

## Definition of Done

Eine Änderung gilt erst als abgeschlossen, wenn Code, Testfälle und Dokumentation denselben Funktionsstand abbilden.
