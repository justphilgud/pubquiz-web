# Qualitätssicherung

Akzeptanzkriterien sollen so formuliert sein, dass daraus direkt Testfälle abgeleitet werden können.

Bei jedem Feature wird geprüft:

1. Ist ein neuer Testfall erforderlich?
2. Muss ein bestehender Testfall angepasst werden?
3. Gehört der Test zur kleinen oder großen Regression?
4. Ist eine Automatisierung sinnvoll?
