# Dokumentationsrichtlinie

## Ziel

Dokumentation und Code werden gemeinsam geändert und im selben Pull Request versioniert.

## Definition of Done

Ein Feature ist erst fertig, wenn:

1. die Implementierung abgeschlossen ist,
2. die Akzeptanzkriterien erfüllt sind,
3. relevante Tests ergänzt oder angepasst wurden,
4. Benutzer- und Administratorhandbuch geprüft wurden,
5. Produktkatalog und Roadmap geprüft wurden,
6. technische und betriebliche Dokumentation geprüft wurden,
7. Changelog oder Release Notes bei sichtbaren Änderungen aktualisiert wurden,
8. nicht betroffene Dokumentationsbereiche im Pull Request ausdrücklich als geprüft markiert wurden.

## Schreibregeln

- kurze und verständliche Sätze
- konkrete Bedienwege
- Rollen und Berechtigungen ausdrücklich nennen
- Screenshots nur ergänzend verwenden
- Dateinamen klein und mit Bindestrichen schreiben
- relative Links verwenden
