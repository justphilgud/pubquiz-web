# Dokumentationsrichtlinie

Code und Dokumentation werden im selben Pull Request geändert.

## Definition of Done
1. Implementierung abgeschlossen
2. Akzeptanzkriterien erfüllt
3. Tests geprüft oder ergänzt
4. Benutzer- und Administratorhandbuch geprüft
5. Produktkatalog und Roadmap geprüft
6. Technik- und Betriebsdokumentation geprüft
7. Changelog/Release Notes geprüft
8. bekannte Einschränkungen geprüft

Nicht verifizierte Details werden als **zu verifizieren** markiert.
